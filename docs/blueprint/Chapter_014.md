\# 1\. Purpose

CMS Engine هسته مدیریت محتوای پلتفرم فرداد است.

هدف این موتور آن است که مدیر سایت بدون نیاز به برنامه‌نویسی بتواند صفحات، محتوا، بلوک‌ها، فرم‌ها، منوها، بنرها، پاپ‌آپ‌ها و اجزای سایت را مدیریت کند.

CMS باید مستقل از قالب (Theme) و مستقل از Frontend باشد.

\# 23\. Architecture Decision 014

تمام صفحات سایت، منوها، فرم‌ها، بنرها، Popupها و Landing Pageها فقط از طریق CMS Engine مدیریت می‌شوند.

هیچ صفحه‌ای نباید داخل کد پروژه Hard Code شود.
